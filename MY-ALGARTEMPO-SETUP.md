# My Algartempo

Portal do colaborador integrado no site Algartempo.

## Ativar a base de dados
1. Abrir o Supabase SQL Editor.
2. Executar `my-algartempo.sql`.
3. Criar utilizadores em Authentication > Users.
4. Para cada colaborador, após o primeiro login, o perfil é criado automaticamente.

## Entrada
Abrir `my-algartempo.html` ou usar o botão MY ALGARTEMPO no site.

## O portal inclui
- Dashboard
- Perfil
- Horários
- Registo de horas
- Férias e ausências
- Vencimentos/recibos
- Documentos
- Pedidos à Algartempo
- Notificações
- Colocação atual
- Login/logout e recuperação de palavra-passe

Os dados pessoais ficam protegidos por RLS no Supabase.
